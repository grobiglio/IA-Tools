# Informe sobre funcionalidades, usos, límites y buenas prácticas de ChatGPT

## 1. Introducción

ChatGPT debe entenderse hoy como una plataforma de trabajo asistido por inteligencia artificial, no simplemente como un chatbot que responde preguntas. Su valor principal está en combinar conversación, razonamiento, análisis de documentos, investigación con fuentes, generación de contenido, análisis de datos, trabajo con imágenes, automatizaciones, memoria, proyectos e integraciones con otras herramientas.

Esto significa que ChatGPT puede ser utilizado en contextos educativos, profesionales, técnicos, administrativos y creativos. Puede ayudar a estudiar, redactar, resumir, investigar, programar, analizar planillas, interpretar documentos, diseñar materiales, planificar proyectos, preparar clases, generar ideas, revisar textos y organizar tareas recurrentes.

Sin embargo, su uso exige criterio. ChatGPT puede cometer errores, inventar información, interpretar mal fuentes o documentos, omitir matices importantes, reproducir sesgos y generar respuestas convincentes pero incorrectas. Por eso no debe utilizarse como autoridad final en asuntos sensibles, legales, médicos, técnicos críticos, institucionales o de alto impacto sin revisión humana experta.

El objetivo de este informe es explicar qué puede hacer ChatGPT, para qué sirve cada función, cuándo conviene usar cada herramienta, qué diferencias hay entre funciones parecidas, qué limitaciones existen y qué precauciones deben tomarse para un uso responsable.

# 2. Qué puede hacer ChatGPT

ChatGPT puede realizar tareas agrupadas en varias familias de capacidades.

## 2.1 Conversar, explicar y razonar

La función básica de ChatGPT es mantener una conversación en lenguaje natural. El usuario puede hacer preguntas, pedir explicaciones, solicitar ejemplos, comparar ideas, revisar argumentos o desarrollar un razonamiento paso a paso.

Sirve para:

* Explicar conceptos difíciles.
* Responder preguntas generales.
* Ayudar a pensar un problema.
* Generar ideas.
* Organizar información.
* Traducir o reformular textos.
* Preparar clases, sermones, informes o presentaciones.
* Revisar redacciones.
* Elaborar resúmenes.
* Ayudar con código o cálculos.

Conviene usar esta función cuando el usuario necesita una primera aproximación, una explicación ordenada, una lluvia de ideas, una revisión de texto o una ayuda conceptual.

Limitación principal: si el tema requiere información actualizada, fuentes verificables o datos muy específicos, la conversación general puede no ser suficiente. En esos casos conviene usar búsqueda web, investigación profunda o documentos adjuntos.

---

## 2.2 Usar distintos modelos

ChatGPT puede ofrecer distintos modelos o modos de respuesta, según el plan y la disponibilidad. Algunos modelos priorizan velocidad; otros, razonamiento más profundo.

En términos prácticos:

* Un modelo rápido conviene para preguntas simples, redacción breve, ideas iniciales o tareas cotidianas.
* Un modelo de razonamiento conviene para análisis técnico, problemas complejos, planificación, programación, comparación de alternativas o revisión crítica.
* Un modelo más avanzado conviene cuando se necesita mayor profundidad, precisión o capacidad para combinar varias instrucciones.

La diferencia no está solo en “calidad”, sino en el tipo de tarea. No siempre hace falta usar el modelo más potente. Para tareas simples, uno rápido puede ser suficiente. Para problemas técnicos, informes complejos o decisiones relevantes, conviene usar un modelo de razonamiento.

---

## 2.3 Crear buenos prompts

Un prompt es la instrucción que el usuario le da a ChatGPT. La calidad del prompt influye mucho en la calidad de la respuesta.

Un buen prompt suele incluir:

* Objetivo claro.
* Contexto suficiente.
* Rol esperado.
* Formato de salida.
* Audiencia destinataria.
* Nivel de detalle.
* Restricciones.
* Ejemplos, si hacen falta.
* Criterios de calidad.

Ejemplo pobre:

> Explicame este tema.

Ejemplo mejor:

> Actuá como docente universitario. Explicá el concepto de sistema de gestión de calidad para estudiantes de ingeniería que recién empiezan. Usá lenguaje claro, ejemplos industriales y una estructura con introducción, desarrollo y cierre. No superes las 600 palabras.

Conviene enseñar prompting como una habilidad central. No se trata de encontrar una frase mágica, sino de aprender a dirigir el trabajo de la IA con claridad.

---

## 2.4 Aprender con ChatGPT

ChatGPT puede funcionar como tutor. Puede explicar temas, hacer preguntas, proponer ejercicios, corregir respuestas, diseñar planes de estudio y adaptar el nivel de dificultad.

Puede servir para:

* Estudiar un tema nuevo.
* Repasar antes de un examen.
* Preparar preguntas de autoevaluación.
* Entender textos complejos.
* Pedir analogías.
* Simular una clase.
* Recibir retroalimentación.
* Aprender idiomas.
* Practicar programación.
* Hacer ejercicios guiados.

Cuando se usa para aprender, conviene pedirle que no entregue simplemente la respuesta final, sino que guíe el razonamiento. Por ejemplo:

> No me des la respuesta directamente. Haceme preguntas para que yo pueda llegar a la solución.

La función de aprendizaje es especialmente útil cuando se combina con documentos propios: apuntes, bibliografía, sílabos, ejercicios, capturas de pantalla o PDFs.

Limitación: ChatGPT puede explicar algo de manera convincente pero errónea. En educación, es importante contrastar con bibliografía, docentes o fuentes confiables.

---

## 2.5 Analizar documentos

ChatGPT puede trabajar con documentos adjuntos: PDFs, Word, Markdown, planillas, presentaciones, imágenes y otros archivos compatibles.

Puede ayudar a:

* Resumir documentos.
* Identificar ideas principales.
* Extraer puntos críticos.
* Comparar versiones.
* Detectar contradicciones.
* Transformar un documento técnico en texto divulgativo.
* Preparar una minuta.
* Elaborar preguntas de comprensión.
* Buscar información específica dentro del archivo.
* Generar tablas a partir del contenido.

Conviene usar análisis documental cuando el contenido relevante ya está en un archivo y no se quiere depender de memoria o conocimiento general del modelo.

Ejemplos de uso:

* “Resumí este informe en 150 palabras.”
* “Extraé los compromisos, responsables y fechas.”
* “Compará estos dos procedimientos y marcá diferencias.”
* “Convertí este documento técnico en una explicación para personal no técnico.”
* “Identificá riesgos, supuestos y pendientes.”

Limitaciones:

* Puede interpretar mal tablas complejas.
* Puede omitir detalles en documentos largos.
* Puede tener dificultades con escaneos de baja calidad.
* Puede fallar con imágenes incrustadas o diagramas complejos.
* No debe reemplazar la lectura experta en documentos críticos.

---

## 2.6 Investigar con fuentes

ChatGPT puede usar búsqueda web o investigación profunda para consultar fuentes externas. Esta función es necesaria cuando el tema es actual, cambiante, especializado o requiere respaldo documental.

La búsqueda web conviene para:

* Preguntas actuales.
* Datos recientes.
* Noticias.
* Precios.
* regulaciones vigentes.
* disponibilidad de productos.
* versiones actuales de software.
* información institucional.
* fuentes oficiales.

La investigación profunda conviene para:

* Informes extensos.
* Comparaciones entre fuentes.
* Revisión de literatura.
* Análisis de tendencias.
* estudios de mercado.
* investigación académica preliminar.
* preparación de cursos.
* informes técnicos o institucionales.

Diferencia principal:

* La búsqueda web responde de forma rápida con fuentes.
* La investigación profunda planifica, consulta múltiples fuentes, sintetiza y produce un informe más estructurado.

Precaución: que una respuesta tenga citas no significa que sea automáticamente correcta. El usuario debe verificar si las fuentes son confiables, si respaldan realmente la afirmación y si están actualizadas.

---

## 2.7 Crear proyectos

Los proyectos permiten organizar chats, archivos e instrucciones alrededor de un objetivo común. Sirven para trabajos de largo plazo.

Conviene crear un proyecto cuando:

* Hay varios documentos relacionados.
* El trabajo durará varios días o semanas.
* Se necesitan múltiples conversaciones sobre el mismo tema.
* Hay instrucciones permanentes para ese trabajo.
* Se quiere conservar contexto.
* Se trabaja en un curso, informe, investigación, planificación o desarrollo.

Ejemplos de proyectos:

* Curso interno sobre ChatGPT.
* Preparación de sermones.
* Informe semanal de gestión.
* Certificación de aeronave.
* Sistema RAG institucional.
* Investigación bibliográfica.
* Plan de capacitación.
* Desarrollo web.
* Proyecto de análisis de datos.

Diferencia entre proyecto y chat común:

* El chat común sirve para tareas puntuales.
* El proyecto sirve para continuidad, organización y contexto persistente.

Precaución: un proyecto no elimina la necesidad de revisar la información. También debe gestionarse con cuidado si contiene archivos sensibles.

---

## 2.8 Usar memoria e instrucciones personalizadas

ChatGPT puede recordar información relevante del usuario y puede recibir instrucciones personalizadas.

Las instrucciones personalizadas son reglas explícitas que el usuario define. Por ejemplo:

* “Respondeme siempre en español profesional.”
* “Cuando me ayudes con informes técnicos, usá tono formal.”
* “Cuando prepare sermones, priorizá enfoque expositivo.”
* “Cuando escribas código, explicá los pasos.”

La memoria permite que ChatGPT recuerde preferencias, contexto profesional o intereses útiles para futuras conversaciones.

Diferencia importante:

* Las instrucciones personalizadas dicen cómo debe responder.
* La memoria conserva información útil sobre el usuario o sus proyectos.

Conviene configurar ambas cuando se usa ChatGPT de forma frecuente.

Precauciones:

* No guardar datos sensibles innecesarios.
* Revisar periódicamente qué recuerda ChatGPT.
* Borrar memorias que ya no correspondan.
* No depender de que la memoria sea perfecta.
* No usar memoria como repositorio formal de información institucional.

## 2.9 Crear contenido escrito

ChatGPT puede ayudar a producir textos de muchos tipos:

* Informes.
* Correos.
* Mensajes de WhatsApp.
* Publicaciones de LinkedIn.
* Artículos.
* Guiones.
* Clases.
* Manuales.
* Procedimientos.
* Sermones.
* Minutas.
* Resúmenes ejecutivos.
* Textos divulgativos.
* Material publicitario.
* Traducciones.
* Reescrituras.

Puede servir en distintas etapas:

1. Ideación.
2. Estructura.
3. Primer borrador.
4. Revisión.
5. Mejora de tono.
6. Reducción de extensión.
7. Adaptación a una audiencia.
8. Corrección final.

Conviene usarlo como asistente de escritura, no como sustituto del autor. El usuario debe revisar contenido, exactitud, tono, intención y pertinencia.

Ejemplo de prompt:

> Redactá un correo formal para solicitar actualización de estado de un trámite. El tono debe ser cordial, claro y profesional. Incluí un pedido concreto de respuesta antes del viernes.

## 2.10 Analizar datos

ChatGPT puede analizar datos cuando se le cargan planillas, CSV u otros archivos estructurados. Puede ayudar a limpiar datos, calcular indicadores, crear tablas, detectar tendencias, generar gráficos y explicar resultados.

Sirve para:

* Explorar bases de datos.
* Detectar valores faltantes.
* Agrupar información.
* Comparar proveedores.
* Calcular porcentajes.
* Crear visualizaciones.
* Generar tablas dinámicas.
* Revisar consistencia.
* Preparar reportes.
* Automatizar transformaciones.

Conviene usarlo cuando el usuario tiene un archivo y necesita una primera exploración o un análisis reproducible. También es útil para quienes no dominan herramientas estadísticas o lenguajes de programación.

Limitaciones:

* Si los datos están mal cargados, el análisis será débil.
* Puede interpretar columnas incorrectamente.
* Puede generar conclusiones sin suficiente base.
* En contextos técnicos o financieros, los resultados deben revisarse.
* No reemplaza auditoría de datos ni validación estadística formal.

Buenas prácticas:

* Explicar qué representa cada columna.
* Indicar unidades.
* Aclarar supuestos.
* Pedir que muestre pasos.
* Pedir revisión de inconsistencias.
* Validar resultados críticos manualmente.

## 2.12 Diseñar tareas recurrentes

ChatGPT puede programar tareas o recordatorios cuando la función está disponible. Esto permite recibir resúmenes, avisos o revisiones periódicas.

Ejemplos:

* “Todos los lunes a las 8, resumime novedades de IA aplicada a ingeniería.”
* “Cada día a las 10, explicame una pregunta de ciencia de datos.”
* “Cada 24 horas, revisá correos no leídos importantes.”
* “Recordame pagar una factura el 1 de julio.”
* “Avisame si aparece una noticia relevante sobre cierto tema.”

Conviene usar tareas cuando hay una necesidad repetitiva, programada o condicional.

Diferencia entre tarea y simple pedido:

* Un pedido en el chat se responde en el momento.
* Una tarea programada se ejecuta después, en una fecha, frecuencia o condición definida.

Limitaciones:

* Puede haber límites de frecuencia.
* Puede depender del plan.
* No debe usarse para decisiones críticas sin revisión.
* En tareas con correo, calendario o documentos, hay implicancias de privacidad.
* Es necesario formular bien qué debe revisar y cuándo debe notificar.

---

## 2.13 Comparar modelos

Comparar modelos permite elegir cuál es más adecuado según la tarea.

Criterios de comparación:

* Velocidad.
* Profundidad de razonamiento.
* Calidad de redacción.
* Capacidad de análisis técnico.
* Manejo de instrucciones complejas.
* Uso de herramientas.
* Costo o límite de uso.
* Precisión.
* Creatividad.
* Consistencia.
* Capacidad multimodal.

Ejercicio típico:

Se toma una misma tarea y se prueba con distintos modelos. Luego se comparan las respuestas según criterios previamente definidos.

Ejemplo:

> Pedir a dos modelos que resuman un informe técnico, detectar cuál conserva mejor los detalles, cuál redacta con mayor claridad y cuál comete menos omisiones.

Precaución: no siempre un modelo más avanzado será mejor para toda tarea. La selección debe hacerse según necesidad.

---

## 2.14 Evaluar errores y alucinaciones

Una alucinación ocurre cuando la IA genera información falsa, inventada o no respaldada, pero presentada con aparente seguridad.

Puede ocurrir en:

* Fechas.
* Citas.
* Normas.
* Referencias bibliográficas.
* Datos técnicos.
* Jurisprudencia.
* Nombres de autores.
* Resultados numéricos.
* Resúmenes de documentos.
* Información médica o legal.
* Enlaces o fuentes inexistentes.

Cómo reducir el riesgo:

* Pedir fuentes.
* Verificar las fuentes.
* Solicitar incertidumbres.
* Pedir que separe hechos de inferencias.
* Pedir que indique supuestos.
* Comparar con documentos originales.
* Usar búsqueda cuando el tema sea actual.
* Revisar cálculos.
* No aceptar citas sin comprobar.
* Pedir una sección de “posibles errores o puntos a verificar”.

Ejemplo de prompt:

> Revisá tu respuesta anterior. Identificá afirmaciones que podrían requerir verificación externa, indicá qué tan seguro estás de cada una y proponé cómo comprobarlas.

* Redacción simple.

* Revisión de estilo.

* Preparación inicial.

No conviene si:

* Se necesita información actual.
* Se requiere evidencia documental.
* Hay datos sensibles.
* La respuesta tendrá impacto institucional o técnico importante.

* Problemas complejos.

* Evaluación de alternativas.

* Planificación.
* Revisión crítica.

* Mensajes cortos.

* Eventos.

No conviene depender solo de búsqueda web cuando:

# 4. Diferencias entre funciones parecidas

## 4.1 Chat común vs proyecto

El chat común es una conversación individual. Sirve para resolver algo puntual. El proyecto, en cambio, organiza varias conversaciones, archivos e instrucciones bajo un mismo objetivo. Conviene usar proyecto cuando el trabajo tiene continuidad.

Ejemplo:

* Chat común: “Redactame un correo.”
* Proyecto: “Curso completo de ChatGPT para una institución.”

---

## 4.2 Prompt vs instrucciones personalizadas

El prompt vale para la conversación actual. Las instrucciones personalizadas se aplican de manera persistente en todos los chats.

Ejemplo:

* Prompt: “Respondé en tono formal esta vez.”
* Instrucción personalizada: “En temas profesionales, respondé siempre con tono formal y estructura ejecutiva.”

---

## 4.3 Memoria vs historial

El historial es el registro de conversaciones pasadas. La memoria es información que ChatGPT puede usar activamente para personalizar respuestas futuras.

Puede existir historial sin que todo se convierta en memoria. También se puede borrar una memoria sin borrar necesariamente el chat original.

---

## 4.4 Búsqueda web vs investigación profunda

La búsqueda web sirve para encontrar y citar información rápidamente. La investigación profunda sirve para construir un informe más completo a partir de varias fuentes.

Ejemplo:

* Búsqueda web: “¿Cuál es la versión actual de una norma o software?”
* Investigación profunda: “Prepará un informe comparativo sobre herramientas de IA para educación.”

---

## 4.5 Análisis de documento vs análisis de datos

El análisis de documento trabaja sobre contenido textual o visual: informes, PDFs, procedimientos, presentaciones. El análisis de datos trabaja sobre estructuras tabulares: planillas, columnas, registros, variables.

Ejemplo:

* Documento: “Resumí este procedimiento.”
* Datos: “Calculá cuántas órdenes están vencidas por proveedor.”

---

## 4.6 GPT personalizado vs proyecto

Un GPT personalizado es un asistente configurado para una tarea específica. Un proyecto es un espacio de trabajo con contexto acumulado.

Ejemplo:

* GPT personalizado: “Asistente para redactar minutas.”
* Proyecto: “Gestión completa de informes semanales de una gerencia.”

---

## 4.7 Tarea programada vs mensaje común

Un mensaje común se responde en el momento. Una tarea programada se ejecuta en el futuro o de forma recurrente.

Ejemplo:

* Mensaje común: “Explicame esta pregunta de ciencia de datos.”
* Tarea: “Todos los días a las 10 explicame una pregunta de ciencia de datos durante 100 días.”

---

## 4.8 Generación de imagen vs análisis de imagen

Generar imagen significa crear una imagen nueva a partir de instrucciones. Analizar imagen significa interpretar una imagen existente.

Ejemplo:

* Generación: “Creá una ilustración de Moisés cruzando el Mar Rojo.”
* Análisis: “Explicame qué muestra esta captura de pantalla.”

# 5. Limitaciones de ChatGPT

## 5.1 Puede equivocarse

ChatGPT no garantiza verdad. Puede responder con seguridad aunque esté equivocado. Esto es especialmente peligroso porque su estilo puede sonar convincente.

Áreas de riesgo:

* Datos técnicos.
* Normas.
* Medicina.
* Derecho.
* Finanzas.
* Seguridad.
* Información reciente.
* Citas bibliográficas.
* Fechas.
* Estadísticas.
* Procedimientos críticos.

---

## 5.2 Puede inventar fuentes o citas

Aunque ChatGPT puede trabajar con fuentes, también puede generar referencias inexactas si no se le exige búsqueda o documentación verificable.

Buenas prácticas:

* Pedir fuentes reales.
* Revisar enlaces.
* Confirmar que la fuente dice lo que ChatGPT afirma.
* Priorizar fuentes oficiales.
* No usar bibliografía inventada.

---

## 5.3 Puede malinterpretar documentos

Aunque pueda analizar archivos, no siempre interpreta correctamente:

* Tablas complejas.
* Escaneos.
* Diagramas.
* Imágenes incrustadas.
* Notas al pie.
* Estructuras poco claras.
* Documentos extensos.
* Versiones con cambios.

Por eso, los documentos críticos deben revisarse manualmente.

---

## 5.4 Tiene límites de contexto

ChatGPT no conserva infinitamente todo lo conversado dentro de un chat. Puede olvidar detalles, priorizar información reciente o perder matices si el intercambio es muy largo.

Buenas prácticas:

* Resumir decisiones tomadas.
* Usar proyectos.
* Repetir restricciones importantes.
* Subir documentos de referencia.
* Pedir que genere una minuta de contexto.

---

## 5.5 Tiene sesgos

La IA puede reproducir sesgos presentes en los datos de entrenamiento, en fuentes consultadas o en la formulación del usuario.

Puede haber sesgos:

* Culturales.
* Ideológicos.
* Lingüísticos.
* Profesionales.
* De género.
* De disponibilidad de información.
* De popularidad de fuentes.

Buenas prácticas:

* Pedir perspectivas alternativas.
* Preguntar por supuestos.
* Comparar fuentes.
* Solicitar objeciones.
* Revisar lenguaje discriminatorio o excluyente.

---

## 5.6 No reemplaza el juicio experto

ChatGPT puede asistir, pero no debe sustituir al profesional responsable. En ingeniería, medicina, derecho, educación, finanzas, seguridad operacional o gestión institucional, el criterio humano experto sigue siendo indispensable.

La IA puede:

* Ayudar a preparar.
* Ordenar información.
* Proponer alternativas.
* Detectar posibles problemas.
* Acelerar borradores.
* Sugerir enfoques.

Pero el profesional debe:

* Validar.
* Decidir.
* Asumir responsabilidad.
* Firmar.
* Autorizar.
* Corregir.
* Contextualizar.

---

# 6. Precauciones con datos sensibles, fuentes, errores y privacidad

## 6.1 Datos personales y sensibles

No conviene ingresar datos sensibles salvo que sea estrictamente necesario y exista autorización.

Datos sensibles incluyen:

* Salud.
* Historia clínica.
* Datos biométricos.
* Datos financieros.
* Contraseñas.
* Documentos de identidad.
* Información laboral reservada.
* Datos de menores.
* Información contractual confidencial.
* Datos comerciales estratégicos.
* Información técnica protegida.
* Correos privados de terceros.

Buenas prácticas:

* Anonimizar datos.
* Eliminar nombres propios.
* Usar ejemplos ficticios.
* Reducir el nivel de detalle.
* Revisar configuración de privacidad.
* No subir documentos completos si alcanza con fragmentos.
* Evitar compartir información de terceros sin permiso.
* Usar planes institucionales cuando corresponda.

---

## 6.2 Fuentes

Cuando se investigan temas con fuentes, conviene distinguir:

* Fuentes oficiales.
* Fuentes académicas.
* Fuentes periodísticas.
* Blogs.
* Opiniones.
* Foros.
* Contenido comercial.
* Documentación técnica.
* Normativa vigente.

No todas las fuentes tienen el mismo peso. Para temas institucionales, técnicos o regulatorios, deben priorizarse fuentes oficiales o primarias.

Buenas preguntas para evaluar fuentes:

* ¿Quién publica esto?
* ¿Está actualizado?
* ¿Tiene autoridad en el tema?
* ¿El texto original respalda la afirmación?
* ¿Hay conflicto de interés?
* ¿Es una fuente primaria o secundaria?
* ¿Otras fuentes confiables coinciden?

---

## 6.3 Privacidad

Antes de usar ChatGPT con información sensible, conviene revisar:

* Si el chat será guardado.
* Si la memoria está activada.
* Si los datos pueden usarse para entrenamiento.
* Si hay apps conectadas.
* Si se está en cuenta personal o institucional.
* Si hay políticas internas de uso de IA.
* Si se compartirán enlaces del chat.
* Si se subirán archivos confidenciales.

Recomendación institucional: definir una política clara de uso de IA generativa, indicando qué puede subirse, qué no, qué debe anonimizarse, quién autoriza y cómo se revisan los resultados.

---

## 6.4 Errores y alucinaciones

Para reducir errores:

* Pedir nivel de certeza.
* Pedir fuentes.
* Pedir que identifique supuestos.
* Solicitar revisión crítica.
* Comparar con documentos originales.
* Verificar números.
* Revisar fechas.
* Consultar especialistas.
* Pedir que separe hechos, inferencias y recomendaciones.

Prompt útil:

> Antes de cerrar la respuesta, listá las afirmaciones que deberían ser verificadas y explicá cómo las verificarías.

# 8. Actividades prácticas para enseñar grupos de funciones

## Actividad 1: Crear buenos prompts

Objetivo: aprender a formular instrucciones claras.

Consigna:

1. Escribir un prompt simple para pedir una explicación.
2. Mejorarlo agregando rol, contexto, audiencia, formato y restricciones.
3. Comparar las respuestas obtenidas.
4. Identificar qué cambió.

Ejemplo:

Prompt inicial:

> Explicá qué es inteligencia artificial.

Prompt mejorado:

> Actuá como docente de nivel secundario. Explicá qué es inteligencia artificial para estudiantes de 16 años. Usá tres ejemplos cotidianos, evitá tecnicismos y cerrá con una pregunta de reflexión.

Criterios de evaluación:

* Claridad.
* Contexto.
* Precisión.
* Formato.
* Utilidad de la respuesta.

---

## Actividad 2: Usar ChatGPT para aprender

Objetivo: experimentar ChatGPT como tutor.

Consigna:

1. Elegir un tema difícil.
2. Pedir una explicación inicial.
3. Pedir tres preguntas de autoevaluación.
4. Responderlas.
5. Pedir corrección y sugerencias de mejora.
6. Pedir una analogía.

Prompt sugerido:

> Quiero aprender el concepto de aprendizaje supervisado. Explicámelo paso a paso, haceme preguntas para comprobar mi comprensión y corregime si respondo mal.

Aprendizaje esperado:

El participante comprende que ChatGPT puede guiar un proceso de estudio, no solo entregar respuestas.

---

## Actividad 3: Analizar un documento

Objetivo: aprender a trabajar con archivos.

Consigna:

1. Subir un documento breve.
2. Pedir resumen ejecutivo.
3. Pedir lista de puntos clave.
4. Pedir riesgos o asuntos pendientes.
5. Pedir una tabla con responsables, fechas y acciones si el documento lo permite.

Prompt sugerido:

> Analizá el documento adjunto. Prepará un resumen ejecutivo de 120 palabras, una lista de puntos críticos y una tabla con acciones, responsables y fechas mencionadas.

Criterios de revisión:

* ¿Incluyó solo información del documento?
* ¿Inventó algo?
* ¿Omitió puntos importantes?
* ¿La tabla respeta el contenido?

---

## Actividad 4: Investigar un tema con fuentes

Objetivo: aprender a usar búsqueda o investigación con respaldo documental.

Consigna:

1. Elegir un tema actual.
2. Pedir una respuesta con fuentes.
3. Revisar las fuentes.
4. Clasificar si son oficiales, académicas, periodísticas o comerciales.
5. Verificar una afirmación contra la fuente original.

Prompt sugerido:

> Investigá brevemente cuáles son las principales recomendaciones actuales sobre uso responsable de IA generativa en educación. Priorizá fuentes oficiales o académicas y citá las fuentes utilizadas.

Aprendizaje esperado:

El participante aprende que las fuentes deben evaluarse, no solo aceptarse.

---

## Actividad 5: Crear un proyecto

Objetivo: entender cuándo conviene usar proyectos.

Consigna:

Diseñar un proyecto llamado “Curso introductorio de ChatGPT”.

Debe incluir:

* Objetivo del proyecto.
* Archivos de referencia.
* Instrucciones del proyecto.
* Tipos de chats necesarios.
* Productos esperados.
* Criterios de éxito.

Ejemplo de instrucción para proyecto:

> En este proyecto, ayudame a preparar un curso introductorio de ChatGPT para adultos profesionales. Usá español claro, ejemplos prácticos y enfoque responsable. Priorizá fuentes oficiales cuando hablemos de funcionalidades.

---

## Actividad 6: Configurar memoria e instrucciones

Objetivo: distinguir memoria, instrucciones y privacidad.

Consigna:

1. Redactar tres instrucciones personalizadas útiles.
2. Proponer tres datos que sí convendría guardar en memoria.
3. Proponer tres datos que no convendría guardar.
4. Discutir por qué.

Ejemplo de instrucción:

> Cuando me ayudes con informes profesionales, usá tono formal, estructura ejecutiva y evitá expresiones coloquiales.

Ejemplo de memoria útil:

> El usuario prefiere respuestas en español profesional latinoamericano.

Ejemplo de dato que no conviene guardar:

> Información médica detallada o datos de identificación de terceros.

---

## Actividad 7: Comparar modelos

Objetivo: aprender a elegir el modelo adecuado.

Consigna:

1. Tomar una misma tarea.
2. Ejecutarla con dos modelos o modos distintos, si están disponibles.
3. Comparar resultados.

Tarea sugerida:

> Prepará una explicación de 300 palabras sobre qué es una evaluación de riesgos, con ejemplo laboral.

Criterios:

* Claridad.
* Profundidad.
* Precisión.
* Velocidad.
* Organización.
* Utilidad práctica.

Conclusión esperada:

No siempre el modelo más avanzado es necesario. La elección depende de la tarea.

---

## Actividad 8: Crear contenido escrito

Objetivo: usar ChatGPT como asistente de escritura.

Consigna:

1. Pedir un primer borrador.
2. Pedir mejora de tono.
3. Pedir reducción de extensión.
4. Pedir adaptación a otra audiencia.
5. Revisar manualmente.

Prompt sugerido:

> Redactá un mensaje institucional para informar una capacitación interna sobre uso responsable de IA. Debe ser claro, cordial y profesional. Luego prepará una versión más breve para WhatsApp.

Aprendizaje esperado:

ChatGPT puede ayudar en varias etapas de escritura, pero el usuario sigue siendo editor responsable.

---

## Actividad 9: Analizar datos

Objetivo: usar ChatGPT para explorar una planilla.

Consigna:

1. Subir una planilla simple.
2. Pedir descripción de columnas.
3. Pedir detección de datos faltantes.
4. Pedir una tabla resumen.
5. Pedir un gráfico.
6. Pedir conclusiones prudentes.

Prompt sugerido:

> Analizá esta planilla. Identificá columnas, datos faltantes, valores extremos y prepará un resumen por categoría. Luego generá un gráfico y explicá qué conclusiones pueden extraerse sin exagerar.

Precaución:

Las conclusiones deben distinguir entre datos observados e inferencias.

---

## Actividad 10: Usar imágenes

Objetivo: aplicar capacidades visuales.

Consigna A: análisis de imagen

1. Subir una captura de pantalla.
2. Pedir explicación de lo que muestra.
3. Pedir diagnóstico probable.
4. Pedir pasos de solución.

Consigna B: generación de imagen

1. Pedir una imagen didáctica.
2. Refinar estilo, público, relación de aspecto y contenido.
3. Evaluar si la imagen cumple el objetivo.

Prompt sugerido:

> Creá una imagen estilo ilustración educativa para niños que muestre una escena bíblica de forma amigable, colorida y no realista.

Aprendizaje esperado:

Las imágenes requieren iteración y especificidad.

---

## Actividad 11: Diseñar una tarea recurrente

Objetivo: aprender a formular automatizaciones.

Consigna:

Diseñar una tarea diaria de aprendizaje.

Debe definir:

* Qué debe hacer ChatGPT.
* Cuándo.
* Con qué frecuencia.
* Extensión.
* Estilo.
* Criterios de contenido.
* Condición de finalización, si aplica.

Prompt sugerido:

> Todos los días a las 10 de la mañana explicame una pregunta de ciencia de datos. La explicación debe ser clara, con ejemplo práctico y no superar las 300 palabras. Hacelo durante 100 días.

Aprendizaje esperado:

Una tarea recurrente debe estar formulada con precisión para evitar ambigüedades.

---

## Actividad 12: Evaluar errores o alucinaciones

Objetivo: desarrollar pensamiento crítico.

Consigna:

1. Pedir a ChatGPT una respuesta sobre un tema técnico.
2. Luego pedirle que revise posibles errores.
3. Buscar fuentes externas.
4. Marcar afirmaciones verificadas, dudosas o incorrectas.

Prompt sugerido:

> Revisá tu respuesta anterior como si fueras un auditor crítico. Identificá posibles alucinaciones, afirmaciones que requieren fuente y puntos donde podrías estar simplificando demasiado.

Criterios:

* Reconoce incertidumbre.
* Diferencia hechos de inferencias.
* No inventa fuentes.
* Sugiere formas de verificación.

---

## Actividad 13: Aplicar criterios de privacidad y seguridad

Objetivo: aprender a decidir qué información se puede compartir con IA.

Consigna:

Analizar cinco casos y decidir si se puede usar ChatGPT, si hay que anonimizar o si no corresponde subir la información.

Casos:

1. Redactar un correo genérico sin datos personales.
2. Resumir una historia clínica.
3. Analizar un contrato confidencial.
4. Preparar una clase pública.
5. Revisar una planilla con nombres, DNI y salarios.

Para cada caso responder:

* ¿Se puede subir tal cual?
* ¿Debe anonimizarse?
* ¿Hace falta autorización?
* ¿Hay política institucional aplicable?
* ¿Qué riesgo existe?

Aprendizaje esperado:

El uso responsable de ChatGPT empieza antes de escribir el prompt.

# 9. Buenas prácticas y advertencias

## 9.1 Verificación de información

Toda información importante debe verificarse. Esto aplica especialmente a:

* Fechas.
* Cifras.
* Normas.
* Citas.
* Datos técnicos.
* Información legal.
* Información médica.
* Información financiera.
* Recomendaciones institucionales.
* Fuentes bibliográficas.

Regla práctica:

> Si una afirmación va a usarse para decidir, publicar, firmar, enseñar o justificar, debe verificarse.

---

## 9.2 Uso responsable de fuentes

Buenas prácticas:

* Pedir fuentes cuando el tema lo requiera.
* Priorizar fuentes oficiales.
* Leer la fuente original.
* No citar algo que no se revisó.
* Distinguir fuente primaria y secundaria.
* Revisar fecha de publicación.
* Identificar conflictos de interés.
* No mezclar opinión con evidencia.
* No aceptar enlaces o referencias sin comprobar.

---

## 9.3 Protección de datos personales y sensibles

Antes de subir información, preguntar:

* ¿Es necesario compartir este dato?
* ¿Puedo anonimizarlo?
* ¿Tengo permiso?
* ¿Hay datos de terceros?
* ¿La organización lo permite?
* ¿Estoy en una cuenta adecuada?
* ¿La memoria está activada?
* ¿Puede quedar guardado en historial?
* ¿Estoy compartiendo un enlace luego?

Principio recomendado:

> Compartir con ChatGPT la mínima información necesaria para lograr el objetivo.

---

## 9.4 Uso institucional

Las organizaciones deberían definir reglas claras.

Una política institucional de IA debería indicar:

* Qué herramientas están autorizadas.
* Qué datos pueden usarse.
* Qué datos están prohibidos.
* Cómo anonimizar información.
* Quién revisa los resultados.
* Qué tareas requieren aprobación.
* Cómo citar el uso de IA.
* Qué responsabilidades conserva el usuario.
* Cómo proteger información confidencial.
* Qué hacer ante errores.

En ámbitos regulados o técnicos, ChatGPT debe ser asistente, no autoridad.

---

## 9.5 Límites de la IA generativa

La IA generativa produce respuestas probables, no verdades garantizadas. Puede ser muy útil para crear, sintetizar y asistir, pero no “comprende” en el mismo sentido que una persona ni asume responsabilidad moral, legal o profesional.

No debe usarse sin supervisión para:

* Diagnóstico médico.
* Dictámenes legales.
* Firma técnica.
* Certificación.
* Decisiones laborales sensibles.
* Evaluación de personas.
* Seguridad operacional.
* Finanzas críticas.
* Automatización institucional sin controles.

---

## 9.6 Sesgos

ChatGPT puede reproducir o amplificar sesgos. Para mitigarlos:

* Pedir perspectivas alternativas.
* Revisar lenguaje.
* Considerar contexto local.
* Evitar generalizaciones.
* Consultar fuentes diversas.
* Pedir análisis de supuestos.
* Incluir revisión humana.

Prompt útil:

> Revisá esta respuesta e identificá posibles sesgos, supuestos culturales o generalizaciones injustificadas.

---

## 9.7 Alucinaciones

Las alucinaciones son uno de los mayores riesgos. Para reducirlas:

* Pedir fuentes.
* Pedir incertidumbre.
* Verificar datos.
* Usar documentos adjuntos.
* Usar búsqueda web.
* Solicitar revisión crítica.
* No aceptar bibliografía sin comprobar.
* Preguntar “¿qué parte de esto no podés verificar?”

Prompt útil:

> Separá tu respuesta en tres columnas: afirmaciones verificadas, inferencias razonables y puntos que requieren verificación externa.

---

## 9.8 Dependencia excesiva

Un uso inmaduro de ChatGPT puede generar dependencia. El usuario puede dejar de pensar, escribir, investigar o decidir por sí mismo.

Riesgos:

* Pérdida de criterio.
* Reducción de habilidades de escritura.
* Aceptación pasiva de errores.
* Delegación indebida.
* Falta de aprendizaje real.
* Producción de contenido genérico.
* Decisiones sin responsabilidad.

Buenas prácticas:

* Usar ChatGPT como colaborador.
* Mantener revisión personal.
* Pedir explicaciones, no solo respuestas.
* Comparar alternativas.
* Conservar pensamiento crítico.
* Aprender del proceso.

---

## 9.9 Necesidad de juicio humano experto

La IA puede asistir, pero el juicio humano sigue siendo central.

El experto humano aporta:

* Contexto.
* Responsabilidad.
* Experiencia.
* Ética.
* Conocimiento situado.
* Discernimiento.
* Priorización.
* Validación.
* Sensibilidad institucional.
* Capacidad de decisión.

La mejor forma de usar ChatGPT no es reemplazar al profesional, sino aumentar su capacidad de análisis, producción y aprendizaje.

# 10. Conclusión

ChatGPT es una herramienta amplia y potente para conversar, aprender, investigar, crear, analizar documentos, trabajar con datos, generar imágenes, organizar proyectos, automatizar tareas y asistir procesos profesionales. Su valor aumenta cuando el usuario aprende a elegir la función correcta: chat común para tareas simples, modelos de razonamiento para problemas complejos, búsqueda para actualidad, investigación profunda para informes documentados, proyectos para continuidad, memoria e instrucciones para personalización, análisis de datos para planillas, imágenes para comunicación visual y tareas programadas para rutinas.

Pero su potencia exige responsabilidad. ChatGPT puede equivocarse, alucinar, sesgar respuestas, malinterpretar documentos y generar una falsa sensación de seguridad. Por eso debe usarse con verificación, control de fuentes, protección de datos, políticas institucionales y revisión experta.

La competencia clave no es solo “saber usar ChatGPT”, sino saber cuándo confiar, cuándo verificar, cuándo limitar, cuándo consultar fuentes y cuándo debe intervenir una persona con conocimiento y responsabilidad profesional.

Usado con criterio, ChatGPT puede ser una herramienta educativa, técnica, administrativa, profesional y creativa de enorme valor. Usado sin criterio, puede amplificar errores. La diferencia la hace el usuario: su claridad al pedir, su prudencia al compartir datos, su capacidad de verificar y su juicio humano al decidir.
