# Inteligencia Artificial: herramientas, recursos y cursos

Este repositorio reúne una colección de contenidos web en español para conocer, aprender y aplicar inteligencia artificial. El proyecto está organizado en tres áreas principales: un directorio de herramientas, una selección de recursos de aprendizaje y materiales para cursos de IA.

## Contenido del repositorio

### Herramientas IA

Directorio web de acceso rápido a plataformas de inteligencia artificial, organizadas por categorías:

- Chatbots
- Investigación
- Agentes
- Productividad
- Automatización
- Vibe coding
- Generación de video e imagen

Incluye información sobre cada herramienta, tutoriales seleccionados, una guía comparativa para elegir una IA y soporte para su instalación como aplicación web progresiva (PWA).

**Acceso web:** [ingg.ar/herramientas-ia](https://ingg.ar/herramientas-ia/)

**Carpeta:** [`Herramientas-IA/`](Herramientas-IA/)

### Recursos IA

Selección curada de enlaces para continuar aprendiendo sobre inteligencia artificial:

- Cursos recomendados en Udemy y YouTube
- Playlists de cursos y tutoriales
- OpenAI Academy
- Capacitación de Google Cloud
- Canales temáticos de WhatsApp

**Acceso web:** [ingg.ar/enlaces](https://ingg.ar/enlaces/)

**Carpeta:** [`Recursos-IA/`](Recursos-IA/)

### Cursos IA

Materiales y páginas web para cursos introductorios y capacitaciones sobre inteligencia artificial. Los contenidos principales abarcan:

1. IA generativa
2. Ingeniería de prompts
3. Funcionalidades de ChatGPT
4. Otras herramientas de IA

La sección también contiene páginas de acceso a cursos, apuntes, evaluaciones, recursos complementarios y demostraciones prácticas.

**Acceso web:** [ingg.ar/curso-chatgpt](https://ingg.ar/curso-chatgpt/)

**Carpeta:** [`Cursos-IA/`](Cursos-IA/)

## Uso local

El repositorio está compuesto principalmente por archivos HTML, CSS y JavaScript, por lo que no requiere un proceso de compilación. Se puede abrir cada archivo `index.html` directamente en el navegador o servir el repositorio con cualquier servidor web estático.
